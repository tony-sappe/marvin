# Evidence types

See also the shared copy at `../../../references/evidence-types.md`.

1. **Proposed** — inferred, not checked.
2. **Confirmed in source** — current code, config, or immutable artifact.
3. **Built** — lint, typecheck, unit test, compile.
4. **Integrated** — test against a real boundary (DB, HTTP, filesystem, browser).
5. **Observed** — runtime or the user's actual end-to-end outcome.

No type subsumes another.
